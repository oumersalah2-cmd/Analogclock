# Analog Clock

A simple analog clock written in Python using Turtle graphics and the `datetime` module.

## What it does
- Draws an analog clock dial with hour numbers (1–12) and tick marks for minutes
- Real-time animated hour, minute, and second hands
- Displays the date and digital time underneath the clock

## How to run
Run the script using Python 3:

```bash
python3 analog-clock.py
```
